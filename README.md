# Dad Jokes Generator

A fun and simple web application that generates random dad jokes to brighten your day!

## Description

This project is a Dad Jokes Generator built using HTML, CSS, and JavaScript. It fetches random dad jokes from the [icanhazdadjoke API](https://icanhazdadjoke.com/) and displays them in a clean, responsive interface.

## Features

- Fetches random dad jokes from an external API
- Responsive design that works on desktop and mobile
- Simple one-click interface to get new jokes
- Error handling for network issues

## How to Use

1. Clone or download the repository.
2. Open `index.html` in your web browser.
3. Click the "Get Another Joke" button to fetch and display a new dad joke.

## Technologies Used

- **HTML**: For the structure of the web page
- **CSS**: For styling and responsive design
- **JavaScript**: For fetching data from the API and handling user interactions
